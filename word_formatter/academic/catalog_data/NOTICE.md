# 高校规范来源与使用

ThesisCraft 的排版配置由项目根据公开规范独立实现，不代表学校审核、授权或保证通过格式审查。适用院系、版本、收录日期、自动设置范围与人工核对事项记录在 index.json。

从 4.2.1 起，新发行包不再捆绑未确认再分发许可的第三方 PDF、DOC、DOCX 或网页全文快照。所有来源记录目前均为 link-only：保留官方 URL、历史版本和校验摘要，用于追溯；不是再分发授权。此前公开版本及 Git 历史中曾收录原件，本次变更不等同于抹去历史副本。

一键应用格式和程序生成的起草 DOCX 可离线使用。新建文件不冒充学校官方模板，不复制学校标识、签字和声明。用户可从来源网站自行取得 DOCX，再通过“导入官方 DOCX”选择本地文件；软件核对已记录版本的 SHA-256，原样复制到另一个文件，保留原件。旧 DOC 请先在 Word/WPS 中另存为 DOCX，按普通文档处理。导出的配置包仅含排版设置、来源元数据及本说明。

原文件的文字、标识等权利仍属原权利人，不适用代码的 MIT 许可。若以后重新捆绑原件，必须记录明确的许可依据、允许范围与署名要求，并重新检查相应开源签名服务的资格。

未规定的格式参数属于可编辑起草建议；最终版式、目录、PDF 字体嵌入、签章和学校审核需另行核对。高校网站可能更新，请以实际提交年份的校级及院系要求为准。
