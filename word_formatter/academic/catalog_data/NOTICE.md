# 高校规范来源与使用

ThesisCraft 的排版配置由项目根据公开规范或明确标记的社区参考资料独立实现，不代表学校审核、授权或保证通过格式审查。适用范围、版本、收录日期、自动设置范围与人工核对事项记录在 index.json。

从 4.2.1 起，新发行包不再捆绑未确认再分发许可的第三方 PDF、DOC、DOCX 或网页全文快照。公开规范的来源记录为 link-only：保留公开 URL、历史版本和校验摘要，用于追溯；不是再分发授权。用户提供的社区参考资料为 metadata-only：仅保存来历、格式摘要和文件校验信息，没有公开链接的资料不会被标为官方来源。此前公开版本及 Git 历史中曾收录原件，本次变更不等同于抹去历史副本。

思政课课程论文参考配置来自用户提供的两页格式资料，原文未注明学校、适用年份或发布日期。北京大学是本次课程使用情境，不构成全校统一标准的证据。该条目不捆绑来源 PDF、示例作者与文献、个人论文或本机路径；无公开链接时界面禁用来源按钮。其明确要求与可编辑默认值分别说明。

一键应用格式和程序生成的起草 DOCX 可离线使用。新建文件不冒充学校官方模板，不复制学校标识、签字和声明。用户可从来源网站自行取得 DOCX，再通过“导入官方 DOCX”选择本地文件；软件核对已记录版本的 SHA-256，原样复制到另一个文件，保留原件。旧 DOC 请先在 Word/WPS 中另存为 DOCX，按普通文档处理。导出的配置包仅含排版设置、来源元数据及本说明。

原文件的文字、标识等权利仍属原权利人，不适用代码的 MIT 许可。若以后重新捆绑原件，必须记录明确的许可依据、允许范围与署名要求，并重新检查相应开源签名服务的资格。

未规定的格式参数属于可编辑起草建议；最终版式、目录、PDF 字体嵌入、签章和学校审核需另行核对。高校网站可能更新，请以实际提交年份的校级及院系要求为准。
