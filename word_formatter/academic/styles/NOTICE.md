# Citation styles

The CSL files in this directory are from the Citation Style Language styles project:
https://github.com/citation-style-language/styles

Downloaded 2026-09-13. Each style retains its upstream authors, contributors,
source links, update date and rights declaration in the XML `info` element.
The styles are distributed under Creative Commons Attribution-ShareAlike 3.0:
https://creativecommons.org/licenses/by-sa/3.0/

ThesisCraft code is MIT licensed. The separate CSL assets retain their upstream license.
The Beijing University 2014 guide references GB/T 7714-2005; the bundled national-standard
CSL is GB/T 7714-2015. Users must confirm the standard required by their current department,
and may supply a custom CSL. This software does not claim institution certification.
