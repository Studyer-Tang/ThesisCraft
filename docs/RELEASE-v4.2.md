# ThesisCraft 4.2 · 高校规范库预览版

新增离线高校规范库：11 所高校、20 个条目，覆盖课程论文、本科、硕士与博士。首批包含北京大学、清华大学、上海交通大学、复旦大学，以及 MIT、Stanford、Oxford、Cambridge；另补东南大学、中山大学 MPA 和上海商学院资料。

- 首页点击“高校模板库”，搜索学校或按论文类型筛选，一键加载已核实的排版设置。
- 保存原始资料包：11 份下载的 PDF/DOC/DOCX 文件与 3 份网页文本快照，记录来源、版本、日期及 SHA-256。
- 对提供 DOCX 的条目可完整复制官方样稿；其他条目生成可编辑 Word 起草骨架，原规范另存于资料包。
- 新增 A4 / Letter / 保留原纸型，英文/课程论文骨架，可保留原分节、页眉、页码与未规定的边距。
- 部分规范只约束正文：只应用选定样式，避免擅自统一封面和院系特殊标题。高级设置可调整应用范围。
- 检查报告附规范来源和人工核对事项。

## 下载

Windows 下载 `.exe`；Apple 芯片 Mac 下载 `macOS-arm64.app.zip`；Intel Mac 下载 `macOS-x86_64.app.zip`。不需要安装 Python。校规资料已随软件打包，使用时无需联网。

## Word 与适用范围

输出为可编辑 DOCX；复制原样稿保留原文件字节。旧版 DOC 可用 Word/WPS 另存为 DOCX。Word/WPS 中需要更新目录域并核对分页；Mac 的 Office 自动化仍需手动完成。未逐项验证商业 Word 各版本的显示一致性。

这是来源可核查的排版辅助库，不是学校认证模板全集。北大保留 2014 校级指南与 2026 哲学系参考初稿的区别；复旦收录 2026-06 修订版，参考文献不误套旧标准；海外院系规范仅适用于标明的项目。课程条目中只有封面/试卷的，默认不改正文。请查阅每个条目的人工核对清单。
