# 4.0.4 验证记录

日期 2026-09-14。作者 Study-Tang，GPT 辅助开发。

## 原生入口

- Windows Word 16.0.20326.20132，64 位；WPS 12.1.0.28043，32 位。
- 使用宿主可执行程序正常启动并打开独立合成文档，核对真实安装路径，避免 WPS 注册为 `Word.Application` 导致误判。
- 两个宿主均自动枚举出 `StudyTang.ThesisCraft`，`Connect=true`；测试没有强制赋值 `Connect`。
- Word/WPS 均显示“学研排版”原生功能区，实际点击“打开排版面板”启动对应宿主的面板，连接的文档名正确。
- 安装 Windows 便携包中的入口后再次正常打开两个宿主，自动连接状态仍为 true；Word/WPS 功能区按钮均实际启动打包的 4.0.4 程序并连接到各自的新测试文档。
- 32/64 位 Rust DLL 均通过 COM 身份一致性、Ribbon 返回、名称解析、错误接口和引用计数释放测试。
- 本机旧 .NET DLL 在普通启动时触发 `clr.dll` 访问违规及 .NET 运行时内部错误；已撤销实验注册，改用不加载 CLR 的 Rust DLL。原来的自动化模式检查不等同于普通启动验收。

## 图片

专项 DOCX 包含超宽、超高、单元格、同段并排和独立横向页图片，共 7 张，另含中英文题注。以北大硕士预设排版后，经真实 Word 导出为 4 页 PDF，并逐页检查图像：全部可见，测试中的图片与题注同页，单元格图片未越界。超高案例在源稿中故意拉伸；程序保持源稿的宽高比例，未擅自恢复裁剪或改变原始媒体。

回归测试覆盖独立图片居中、正文行内图标布局保留、小图不放大、横竖分节边界、表格单元格边界、并排总宽度、重复执行稳定性与媒体字节保留。浮动图片、文本框、复杂手动分页仍保留原布局，需用户在最终打印预览中确认。
