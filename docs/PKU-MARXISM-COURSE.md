模板 ID 为 `pku-marxism-course`，在“高校模板库”中搜索“思政”“马原”或“PKU”，并筛选“课程论文”即可选择。它适用于本次北京大学思政课课程情境及采用同一规范的课程论文。教师另有要求时，可在高级设置或导出的 JSON 中调整。

依据是用户提供的《思政课课程论文格式.pdf》，共2页，2026-10-13核对。文件正文未注明学校、适用年份或发布日期，因此“北京大学”是使用情境，不代表已证明北大全校现行统一标准。来源记录采用 `user-provided` / `metadata-only`，没有已核验公开 URL；界面显示来历并禁用来源按钮，发行包及导出包均不包含原PDF。记录的 SHA-256 为 `92d7d6acc638b6e92d73cd22292b0a84f4885f822abcce4721e6963da86afd7f`。

## 原资料明确规定的格式

| 项目 | 要求 | 原资料位置 |
| --- | --- | --- |
| 论文题目 | 居中，黑体三号（16磅）；段前、段后“0.5”，未说明单位；未明确要求加粗 | 第1页，第1项 |
| 论文副标题 | 黑体小三（15磅）、加粗、居中 | 第1页，第1项 |
| 作者署名 | 居中，宋体小四（12磅）；段前、段后“0.5”，未说明单位 | 第1页，第2项 |
| 摘要和关键词 | 空两字，宋体小四、中文冒号、加粗、1.5倍行距；关键词用中文分号分隔 | 第1页，第3项 |
| 正文 | 宋体小四（12磅），1.5倍行距 | 第1页，第4项 |
| 一级标题 | 一、二、三……；居中，黑体四号（14磅）、加粗；附带副标题黑体小四（12磅） | 第1页，第4项 |
| 二级标题 | （一）（二）（三）……；宋体小四、加粗，前端空两字 | 第1页，第4项 |
| 三级标题 | 1. 2. 3. ……；宋体小四，前端空两字；未明确要求加粗 | 第1页，第4项 |
| 四级标题 | （1）（2）（3）……；宋体小四，可以接在正文行内 | 第1页，第4项 |
| 脚注 | 使用脚注，每页重新排序为①②③……；宋体小五（9磅），单倍行距 | 第1页，第5项 |
| 图表题目 | 黑体小四（12磅）、加粗，采用简单顺序编号 | 第2页，第6项 |
| 图表说明与表格数据 | 宋体五号（10.5磅） | 第2页，第6项 |

原资料的摘要和关键词“加粗”没有完整样段说明其范围。本模板只加粗标签及中文冒号，内容保持常规字重；这是实现解释。一级标题主副标题使用不同字号是明确要求，但原资料没有规定必须有副标题，也没有指定唯一分隔符。文献部分提供著录示例；排版程序保留作者已有脚注和书目，不生成作者、年份、卷次、页码或网络来源。

## 可编辑默认值

| 项目 | 本模板默认 | 与原资料的关系 |
| --- | --- | --- |
| 前置内容 | 题目、副标题、署名、摘要、关键词与正文连续排版；没有独立封面或目录 | 原资料未要求独立封面或目录 |
| 纸型与边距 | A4，四边2.54厘米，装订线0；页眉页脚距离1.27厘米 | 原资料未规定这些参数 |
| 题目和署名段间距 | 题目前后8磅，署名前后6磅 | 按各自字号的0.5倍换算；源“0.5”的单位未明 |
| 正文细节 | 首行空两字、两端对齐；英文和数字使用Times New Roman；文字为黑色 | 正文项仅明确字体、字号和行距 |
| 一级标题分隔 | 首个中文冒号“：”之前14磅，之后12磅；冒号留在主标题部分 | 分隔方式与副标题继承加粗是默认实现 |
| 图表细节 | 题注居中，图与表分别顺序编号，保留已有正确标签；表格行不拆分，图片最大宽度15.2厘米 | 位置、居中、线条及图像宽度未被原资料规定 |
| 页码及分页 | 起草文件使用居中阿拉伯页码；已有稿件保留分节、页眉页脚和页码；标题与后文相连，脚注段尽量不跨页 | 页码及分页保护是版式策略 |
| 参考文献 | 提供可编辑文献区域及悬挂缩进，不启用书目转换 | 原资料未要求固定文末编号或自动转换 |

起草文件提供可删除的副标题占位，作者信息栏留空。副标题可通过 `metadata.title_en` 配置填写；此字段在本课程模板中用于论文副标题。模板不带入来源示例的姓名，也不生成学号、院系、班级或授课教师信息。已有稿件的身份信息与正文保持原值。通用骨架用于作者填写内容，不附带某篇论文的章节、论证、数据、参考文献或图形。

脚注使用Word原生锚点和脚注部件，配置为每页从①开始；没有脚注的稿件不会被凭空补上引文。现有来源超链接、图片和引用域保留。脚注的准确性由作者核实；实际分页和每页编号须在提交使用的Word/WPS中核对。

## 使用方法

```sh
# 新建空白课程起草文件
thesiscraft thesis new --template pku-marxism-course -o course-draft.docx

# 对已有稿件生成独立排版副本
thesiscraft thesis format -i course.docx --template pku-marxism-course

# 只检查，不生成排版副本
thesiscraft thesis check -i course.docx --template pku-marxism-course

# 导出可编辑配置及来源摘要，不包含原PDF
thesiscraft thesis template-bundle --template pku-marxism-course -o course-settings.zip

# 导出JSON，便于长期使用自己的调整
thesiscraft thesis template --template pku-marxism-course -o course-template.json

# 禁用按中文冒号区分一级标题主副标题的便利选项
thesiscraft thesis format -i course.docx --template pku-marxism-course \
  --set 'course.heading_subtitle_separator=""'
```

不带副标题的一级标题全部使用14磅。冒号只是默认的语义约定：如果标题中的冒号不表示主副标题，应置空禁用解析，或在自己的配置中指定适合该稿件的分隔方式。模板默认保留原有标题和图表编号，不将课程标题改为研究生章号，也不把图表改成带章号的编号。

每次排版生成新副本，原稿不覆盖。模板不默认清除斜体、粗体或下划线，也不改写正文或替换事实来源。
