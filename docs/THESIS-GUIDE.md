# 学研排版 4.0：论文工作台

作者：Study-Tang。所有处理在本地进行，原文档不覆盖。

## 三步开始

1. 双击 `start-paper-studio.cmd`，或便携包中的 `Paper-Studio.cmd`。
2. 选择 DOCX 和模板，点击“只检查”。在“结构确认与文献”中校正不确定的标题或题注。
3. 勾选需要处理的项目，选择 Word 或 WPS，点击“排版并生成副本”。可同时导出 PDF，完成后打开检查报告。

每次结果放在原文件旁的独立文件夹，包含 DOCX、所用模板、HTML/JSON 检查报告，以及可选 PDF。报告可以筛选问题、跳到对应段落、查看文字变化、打开原件和 PDF 分页预览。取消会在处理步骤之间生效；正在进行的 Office 更新有 180 秒超时。

## 模板和字体

- 内置北京大学硕士、博士研究生预设，以及本科、硕士、博士通用预设。
- 可设置学校、学院、年份、模板版本；JSON 导入导出，或从 DOCX 样稿读取已有字体、字号、行距和边距，再确认剩余规则。
- 论文题目、英文题目、四级标题、正文、中英文摘要、关键词、图表题注、公式、参考文献、表头、表格、脚注尾注、附录、致谢、符号表、成果、页眉页码、目录等均有单独样式。
- 字体下拉框包含本机已安装字体，也允许输入字体名；中西文字体分开。字号可输入 10.5、11、12、13 等数值，行距可选倍数或固定磅值。
- 编号可跟随对应标题/题注字体，也可取消“跟随”，单独指定编号中西文字体、字号和粗体。
- 章标题支持“第1章”“第一章”“1”“Chapter 1”，下级支持 1.1、1.1.1、1.1.1.1；附录可用 A/B/C 或数字。图表公式可按章编号，分隔符和公式括号可选。

## 北京大学预设的依据

主要依据研究生院公开的《研究生学位论文写作指南》，正文日期为 **2014 年 5 月**，网站附件地址为 2019 年；另读取了 2024 博士格式模板，核对页面边距。

- [研究生院材料下载页](https://grs.pku.edu.cn/xwgz11/xwsy11/bsxw111/clxz09/index.htm)
- [研究生学位论文写作指南 PDF](https://grs.pku.edu.cn/docs/2019-05/20190524160158375113.pdf)
- [博士研究生学位论文格式模板（2024）](https://grs.pku.edu.cn/xwgz11/xwsy11/bsxw111/clxz09/50118yjsy346375.htm)

预设采用：正文宋体小四、英文/数字 Times New Roman、固定20磅；章标题黑体三号、中文数字；二级14磅、三级13磅；页边距上3.0、下2.5、左右2.6厘米，装订线0；页眉2.0、页脚1.75厘米；前置页罗马页码、正文阿拉伯页码居中；图表序号以小数点连接。

这不是北京大学认证软件。上述指南不是2026年发布，院系与当年要求必须再次核对。北大本科请使用本科通用预设，再导入本院系样稿，不能套用研究生预设。2014指南引用 GB/T 7714-2005，而本软件内置 CSL 为 GB/T 7714-2015；如院系指定其他版本，应导入对应 CSL 或继续用文献管理器。

## 文档结构、分页和目录

采用真正的 Word 标题样式与多级编号；未知编号段落在报告中标记为待确认。结构面板允许批量设置段落类型。

摘要、英文摘要、正文各章、参考文献、附录、致谢等可独立分节。支持奇偶页眉、章节页眉、页眉线、装订边、对称页边距、章从奇数页开始、保留横向页面，以及宽表单独横向页。

目录、图目录、表目录使用可更新域。北大预设默认不生成图表目录，符合指南“通常不需要”的说明；可自行勾选。Word/WPS 在双面布局与页码重新从1开始时，可能插入留白页，报告会列出 PDF 空白页供确认。

## 图表、公式和引用

已有标准题注可识别并编号；也可在插件中使用“插入编号/引用”。在纯文本输入中，可使用：

```text
{{fig:flow}} 研究流程
{{table:results}} 实验结果
{{eq:energy}} E = mc²
如 {{ref:fig:flow}} 所示。
已有研究 {{cite:smith2024}} 表明……
```

图表公式编号使用 SEQ，交叉引用使用书签和 REF，可用插件更新。中英文相邻题注可共享序号。已有 Word 公式、MathType 嵌入对象保留，独立公式可设置居中、右侧编号；行内公式不强制转成独立公式。不要给已有复杂公式直接粘贴文本来替换对象。

表格支持三线表、重复表头、禁止单行跨页、线宽选项；可按指定数据行数拆成续表（0表示不拆分）。纵向合并表格不自动拆分，避免破坏合并关系；行数拆分不能代替对实际打印跨页位置的检查。图片可等比缩小到最大宽度，报告检查有效 DPI；不会将低清图片伪装成高清图片。

## 文献库与 CSL

可导入 RIS、BibTeX 或 JSON，渲染器使用 CSL。内置 GB/T 7714-2015 顺序编码、APA、IEEE；可选自定义 CSL。自定义样式需与所选数字/作者年份引用方式一致。常见期刊、图书、会议、学位论文、报告、网页有字段映射；不支持的类型会报错，缺失著录字段进入报告，不会凭空补写。

JSON 示例：

```json
[{"key":"smith2024","type":"journal","authors":["Smith, Jane"],"title":"Example study","year":"2024","journal":"Example Journal","volume":"2","issue":"1","pages":"1-10","doi":"10.example/test"}]
```

示例 DOI 只是填写格式示意。请导入真实文献资料。Zotero/EndNote 原有域保留，其样式仍由原管理器更新；不要混用两套管理器来重复生成同一参考文献列表。数字引用支持对本工具生成的条目重新生成与更新；作者年份引用的内容修改建议从保留标记的源稿重新生成。CSL 资产的作者和许可保留在 `word_formatter/academic/styles/NOTICE.md` 中。

## 封面、声明、符号表与章节

“新建论文骨架”根据填写的信息生成封面信息、中英文摘要、正文、参考文献及辅助章节。学校的封面、版权页、声明和授权页通常是固定格式，应从官方取得；可选择仅含这些前置材料的 DOCX 作为正式前置页。

自己的前置页模板可使用 `{{title}}`、`{{title_en}}`、`{{author}}`、`{{student_id}}`、`{{supervisor}}`、`{{date}}`、`{{school}}`、`{{department}}` 占位，生成时填写，保留原模板与图片。签字、研究内容、摘要和声明正文仍需本人核对填写。

符号/缩略语 CSV 支持 `symbol,meaning,unit` 三列（unit可选），导入后生成符号表。章节工具支持确认顺序、上移下移、合并副本和按章拆分。合并使用第一个文件的页眉页脚作为基础；重复命名书签会拒绝合并并提示处理。拆分文档中的跨章引用需在完整论文中更新。

## 插件操作

- “快速论文排版”：使用工作台保存的默认论文模板生成新副本、更新目录、打开结果。
- “论文设置/检查”：带入当前文件，打开工作台。
- “插入编号/引用”：选择题注、公式、引用、脚注或尾注；交叉引用可以选择已建立的目标。
- “更新目录与引用”：更新当前文档中的目录、编号、页码和引用，随后自行保存。
- “导出论文 PDF”：复制当前已保存文档，更新域并导出 PDF，不重新应用排版规则。
- “排版为新副本”和“排版设置/桌面版”：继续提供原通用排版流程。

工作台可启用或关闭登录后自动连接。启用后等待已打开的 Word/WPS，不主动启动宿主；未启用时可双击启动脚本。请将便携包放在稳定目录后启用自动连接。标准 COM DLL 仍为实验入口，当前推荐的是已验证的外部工具栏；不同 WPS 版本仍可能有宿主差异。

## 检查边界

检查涵盖结构、标题跳级、样式、字号、边距、占位内容、失效书签、图片宽度和 DPI、复杂对象提示，以及北大摘要长度建议。完整性检查保护图片、嵌入对象、公式、修订节点、书签和文献管理器域。报告不声称覆盖所有学校条款、PDF/A认证、查重或科研质量。

修改不覆盖原件。复杂文本框、跨页合并表、页眉中的图片和模板特有对象，需要在 Word/WPS 或最终 PDF 中检查。若宿主更新破坏受保护内容，保留更新前的排版副本，并在报告中说明失败。

## 命令行

```powershell
python wfp_cli.py thesis check -i thesis.docx --template pku-master
python wfp_cli.py thesis format -i thesis.docx --template pku-doctor --host word --pdf
python wfp_cli.py thesis format -i thesis.docx --template master --references library.ris --host wps
python wfp_cli.py thesis format -i thesis.docx --only styles,numbering --set styles.body.size=12
python wfp_cli.py thesis template --template pku-master -o my-template.json
python wfp_cli.py thesis new --template pku-master -o new-thesis.docx
python wfp_cli.py thesis merge cover.docx chapter1.docx chapter2.docx -o combined.docx
python wfp_cli.py thesis split -i combined.docx -o chapters
```

论文检查/排版命令退出码：0 完成且无错误级检查项；2 完成但发现错误级检查项；1 执行失败。待确认项不会被伪装成“学校审核通过”。
