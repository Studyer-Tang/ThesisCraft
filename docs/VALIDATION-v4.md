# 4.0 本机验证记录

- 39 项回归测试通过：包括 18 项论文模式测试、21 项已有回归测试。
- 24 项原有测试中 23 项通过；LibreOffice 集成测试因本机未安装跳过。合计 62 项通过、1 项跳过。
- 论文工作台构造、72 个可配置控件收集、模板验证与生成排版副本通过。
- 真正的 Word/WPS 工具栏按钮触发论文任务、后台排版、更新域、自动打开结果，原件字节未改变，两端均通过。见 `addins/windows/academic_smoke_test.py`。
- Word/WPS 实际导出的 PDF 中，章编号“第一章”与下级“1.1”均正确显示；题注、公式和文献引用更新通过。
- PDF 样本包含目录书签，未检测到失效引用文字或缺少嵌入数据的字体。双面排版因前置页/正文重新编号产生的空白页进入报告，供打印检查。
- 已查看工作台窗口和 Word PDF 的正文页渲染，检查了编号、公式右侧编号、三线表、页眉及页码。
- 长文档样本：1,524 段、336,175 字符，核心排版约 5.59 秒，完整性检查通过；Word 更新生成 323 页，更新过程约 16.34 秒。该样本以正文为主，不代表同页数的图片/公式密集论文也有相同耗时。
- Windows 4.0 EXE 实际启动论文工作台和通用桌面版，基础排版与 CSL 文献资源加载通过。
- 打包 EXE 自身调用 Word/WPS 完成论文排版、更新与 PDF 导出，两端均通过。
- Ruff、Python 编译及差异空白检查通过。

相关本地诊断位于 `build/academic-validation/`、`build/packaged-academic-word/`、`build/packaged-academic-wps/` 和 `dist/*packaged*.json`。这些是测试产物，不含用户论文。

## 仍需按使用环境验证

- 未宣称通过北京大学、其他学校或院系的格式审核；模板基于可核实的公开资料，需确认当年补充要求。
- macOS/Linux、其他 Word/WPS 发行版本、所有 MathType 版本和各类复杂学校模板未逐一验收。
- 标准 COM DLL 自动加载仍是旧实验入口；4.0 使用外部工具栏，可由用户启用登录后自动连接。自动连接设置没有在本次开发中默认启用。
- 文献管理器域保持原管理器所有权；CSL 输入必须提供正确且完整的元数据。作者年份引用修改可从保留标记的源稿重建。
- PDF 检查不是 PDF/A 认证；纵向合并表的拆分、所有文字框和复杂浮动对象仍需视觉确认。

以上为开源发布前的功能验证记录，没有修改用户已有论文，也没有替用户签署声明或自动接受修订。
