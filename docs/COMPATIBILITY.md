# 兼容性与验收记录

2026-09-30，4.2.1 预览版。代码能读写 DOCX 不代表所有 Office 版本都能得到相同分页。

## 已完成的工程检查

- 回归测试覆盖原件与已有输出保护、跨卷临时文件发布、中文及空格路径、Office 超时/崩溃/文件锁、公式/修订/引用保留、模板范围与纸型、字体别名及缺失字体提示。
- 桌面通过 Tk 枚举本机字体，工作线程不访问 UI。字体检查只告知，不擅自替换、不捆绑商业字体。CLI 无图形环境时明确记录“字体未检测”。
- Windows 冻结包在 Windows Server 2022 x64 CI 上构建、自检；新增按用户安装、已安装程序自检、卸载验证。此环境不等同于 Windows 11 家庭版实机验收。
- Mac 构建矩阵为 macOS 15 Apple Silicon 和 Intel；本机额外测试 macOS 26.4 arm64。打包自检不依赖用户已安装的 Python。暂不声明更早 macOS、Windows 10 或 Windows ARM64 原生支持已通过验收。
- 1000 段中英文合成文档在本机 Python 3.13.15 约 1.44 秒完成格式处理和 HTML/JSON 报告，完整性检查通过。复现命令：`python packaging/benchmark.py`。不是复杂论文性能保证。
- 修复长编号段落导致大量分节的问题；显式 Heading 样式仍优先，普通列表样式与完整句子不会仅凭开头数字变成章节。

## 尚未完成的实机验收

本机安装了 Mac Word 16.113.3，但显示未激活，只读模式不能完成编辑/目录更新验收；本轮 GUI 调用也未稳定完成文档预览，未宣称视觉通过。未购买或开启付费试用。Windows Word/WPS 与 Mac WPS 的实际分页对照、OneDrive/iCloud 同步冲突、只读/网络文件系统和多显示器缩放仍需实机验证。

复核时使用合成测试文档，不使用真实论文里的个人信息。建议固定同一份文件、字体及应用版本，对照以下项目并记录系统、Office 版本与截图/PDF：

| 项目 | 验收标准 |
| --- | --- |
| A4 / Letter、横向表格与分节 | 纸型、边距、节数与规则一致，无意外空白页 |
| 中英文字体、行距和标题 | 无静默替代、裁切、编号重复；清楚显示缺失字体 |
| 目录、交叉引用、题注 | 更新后页码可用，无失效书签或重复计数 |
| 公式、脚注、图表、Zotero/EndNote、修订 | 对象保留，原稿摘要不变；不误接受修订 |
| PDF | 页数、字体嵌入、链接、图表分页与 Word 打印预览对应 |
| 中文长路径、Office 锁定、云盘只读/离线 | 错误可理解；保留原件与先前副本，不出现半写入输出 |
| 高分屏、键盘和屏幕阅读器 | 按钮可达、焦点可见、缩放后无截断 |

## 更新、回退与签名边界

更新仅在用户点击时查询 GitHub，不在启动时联网、不下载或运行更新程序。分开查看正式版和预览版，下载地址固定到本项目发布页。用户安装前核对发布状态和签名；历史版本可从发布页恢复。真正的后台自动更新、下载签名验证与自动回滚尚未实现，不将本入口宣传为自动更新器。

源码提供强制签名构建接口，但本轮无开发者私钥、身份审批或 CA 账户，正式签名与公证尚未执行。参见 [SIGNING.md](SIGNING.md)。稳定版发布需补齐以上实机记录及可信签名。
