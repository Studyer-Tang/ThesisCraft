# ThesisCraft 4.2.1 预览版

本版修复长编号正文误识别为章节造成的分节膨胀；收紧标题识别，保留显式 Heading 样式和短编号标题。新增系统字体检查、桌面完整检查报告和用户主动检查更新入口，仍在本地处理文档。

- Windows：提供按用户安装的 Setup.exe（无需管理员权限、可卸载）和 portable.zip。安装版使用目录布局，启动时无需每次解压整个 Python 环境。便携版必须解压整个文件夹。
- Mac：Apple 芯片和 Intel 分别提供 DMG 与 app.zip。DMG 拖入 Applications 即可安装。
- 发布流水线增加安装/卸载验证、DMG 完整性检查及冻结程序自检。
- 签名工具链支持 Developer ID + notarytool + stapler 和 Windows Authenticode + SHA-256 时间戳；缺少配置时 `--signed` 立即失败，绝不静默降级。本次公开构建仍未签名、公证。
- 20 项高校配置继续离线可用。许可未确认的原件已移出新包；通过官方来源自行下载，并可导入已登记版本的本地 DOCX。
- 排版失败、Office 崩溃或报告写入失败不会覆盖原文档；Office 报告按任务隔离。

自动验证不等于真实 Office 分页验收。Mac Word 的目录/引用更新及 PDF 导出仍由用户在 Word 内完成；Windows 自动化需要本机安装相应 Word/WPS。Windows ARM64 尚无原生构建，不声明已验收。最低系统版本以实际测试清单为准。

升级前关闭程序，安装到原位置；便携版放入新文件夹。配置和论文位于程序目录之外。需要回退时从 GitHub 历史发布页重新安装旧版，先备份自己的配置。本版检查更新只打开官方发布页，不在后台下载、安装或执行远程程序。
